# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately using GitHub's [private vulnerability reporting](https://github.com/rapidshyft/TryGradeX/security/advisories/new) on this repository.

Include:
- What you found and where
- Steps to reproduce
- The app version (Settings > About) and your Android version

We aim to acknowledge reports within 3 business days and will keep you updated until the issue is resolved.

## Supported versions

Only the latest release listed on the [Releases page](https://github.com/rapidshyft/TryGradeX/releases/latest) receives security fixes.

## Verifying downloads

Only install GradeX from this repository or [trygradex.app](https://trygradex.app), and check the APK against `SHA256SUMS.txt` attached to each release. If you find a copy of GradeX hosted elsewhere, please report it.
